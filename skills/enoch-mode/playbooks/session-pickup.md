# Session pickup

Use when continuing another agent's or an earlier session's unfinished work.

1. Locate the handoff, issue or spec, plan, branch, PR, and available evidence in the current project's scope. Do not search unrelated private sessions. Read the latest checkpoint first, then the decisions needed to understand the remaining work.
2. Inspect the current worktree and remote state without overwriting either. Separate completed, in-flight, and unstarted work. Compare inherited claims with commits, diffs, tests, or product artifacts; a prior agent's summary is not proof by itself.
3. State the resume point and choose the relevant playbook for the remaining request. Preserve settled product decisions unless new evidence conflicts with them. Recheck only what is needed to trust inherited work, then continue instead of restarting it.
4. Report what you inherited, what you verified independently, what remains, and any assumption you changed.

If a handoff conflicts with the user's current request, follow the current request and explain the conflict.
